# 🧲 Nursultan Client | AutoPickup

**Your loot. Your time. Your advantage.**

AutoPickup is a loot collection script designed for **Nursultan Client**. It automatically searches for nearby dropped items and navigates towards them.

### ⚡ Features
- 🔎 Automatic item detection
- 🏃 Automatic movement towards loot
- 🗺️ Pathfinding and jumping
- 🌊 Water escape logic
- ⚙️ Customizable settings

### 🎮 Compatibility
- **Client:** Nursultan Client
- **API:** v9
- **Minecraft:** 1.21.11
- **Format:** Kotlin Script (`.kts`)

### 🚀 Why AutoPickup?
Spend less time chasing drops and more time playing.

**Less running. More loot.**
